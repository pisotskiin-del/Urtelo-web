{% icon "list" %} Что произойдёт

  • Месяц {{ mes }} {{ god }} сохранится в архиве: карты абонентов и исходные данные по городам.
  • Для 1С подготовится файл начислений Abot (абоненты с начислением больше нуля){% if dir_1c %} и запишется в папку {{ dir_1c }}{% else %}; его можно скачать в «Закрытых месяцах»{% endif %}.
  • «Выставлено с начала финанс. года» и «с начала отопит. сезона» увеличатся на начисленное за месяц, пересчитается остаток лимита.{% if year_reset %} Январь: накопления за год и лимиты сначала обнулятся.{% endif %}{% if season_reset %} Октябрь: накопление за отопительный сезон сначала обнулится.{% endif %}

  • Во всех городах установится месяц {{ next }}; нагрузка котельных обнулится.
